# Security Policy

## Supported project status

This project is open source and maintained as a practical creator and education workflow tool. Security reports are welcome for the public repository.

## Reporting a vulnerability

Please do not disclose exploitable details in a public issue.

To report a vulnerability, open a GitHub issue with a brief non-sensitive summary and request a private maintainer contact, or contact the maintainer through the GitHub profile at https://github.com/kennynwokoye.

Please include:

- Affected area
- Impact summary
- Reproduction steps, if safe to share privately
- Suggested fix, if known

## Security areas of interest

- Referral link abuse and duplicate-click handling
- Supabase row-level security policies
- API route authorization
- Secret handling and environment variable exposure
- Payment or unlock bypass risks
